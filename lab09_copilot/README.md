# Lab 09 - Resolvendo Códigos em Python com GitHub Copilot

Este laboratório faz parte do **Bootcamp DIO - Back-end com Python**, mas foca em **prática de lógica e programação em Python** utilizando recursos de IA para auxiliar na codificação.

---

## 🐾 1 - Concatenando Dados

**Descrição:** Vamos receber dois dados diferentes do usuário e concatená-los em uma única string.  

**O que aprenderemos:**
- Manipulação de Strings (`string`)
- Concatenação
- Entrada de dados
- Utilização eficiente do GitHub Copilot

---

## ✏️ 2 - Repetindo Textos

**Descrição:** Agora vamos solicitar uma string e um número inteiro como entrada. Depois retornaremos a string repetida o número de vezes informado.

**O que aprenderemos:**
- Manipulação de Strings (`string`)
- Números Inteiros (`int`)
- Múltiplas repetições
- Entrada de dados
- Aproveitar as sugestões do GitHub Copilot

---

## 📐 3 - Operações Matemáticas Simples

**Descrição:** Solicite dois números e realize uma operação simples entre eles.

**O que aprenderemos:**
- Operações Matemáticas Básicas
- Entrada de dados
- Utilização eficiente do GitHub Copilot

---

## 🧮 4 - Verificando Números Pares e Ímpares

**Descrição:** Receba um número inteiro e verifique se ele é par ou ímpar.  

**O que aprenderemos:**
- Condicionais em Python (`if`, `else`)
- Operador de módulo (%) para verificação de paridade
- Exploração de ferramentas de IA para otimização de código

---

## 📚 5 - Calculando Média de Notas

**Descrição:** Calcule a média de três notas fornecidas pelo usuário.  

**O que aprenderemos:**
- Uso de variáveis para armazenar dados do usuário
- Aplicação de operadores aritméticos (`+`, `/`) para média
- Manipulação de entrada do usuário

---

## 🔄 6 - Verificando Palíndromos

**Descrição:** Teste se uma palavra é um palíndromo.  

**O que aprenderemos:**
- Manipulação de strings em Python
- Comparação entre a string original e invertida
- Introdução ao conceito de palíndromos e sua aplicação

---

## ⚙️ Tecnologias e Conceitos Praticados

- Python 3
- Entrada e saída de dados (`input`, `print`)
- Manipulação de strings e números
- Operadores aritméticos e condicionais
- Prática com ferramentas de IA (GitHub Copilot ou ChatGPT)
